# Two Unknown Variables — V4 Galaxy Edition

## Run it
1. Extract this ZIP into a new folder.
2. Open `index.html` in a modern browser.
3. Tap/click the background to create star ripples and particles.
4. Use the timeline slider, play/pause controls, story-tone choices, and constellation button.

## Install on Android
This is a lightweight Progressive Web App source project, not a compiled APK. For the install prompt and offline caching, host the folder on an HTTPS static host, open its URL in Chrome, then choose **Install app** or **Add to Home screen**. Some browser features vary.

## Design note
The graphs are metaphorical illustrations, not real data and not predictions about anyone's feelings. The message is intentionally respectful: a meeting creates an opportunity, not an obligation.


## Background music (V5)
The supplied `Untitled.mp3` track is included as `background-music.mp3` and loops in the background. Browsers generally block autoplay, so the listener must tap **Play music** once. The floating control includes pause/resume and a volume slider. The music track is included only in this local project ZIP.


## V6 music troubleshooting
The music player now also has native browser controls visible at the bottom-left, in addition to the floating Play/Pause and volume controls. Keep `background-music.mp3` in the same extracted folder as `index.html`. If the browser blocks playback or the custom button fails, tap the native player's play icon.


## V7 embedded audio
The uploaded MP3 is embedded directly into `index.html`, so the page no longer needs to find a separate music file. This is intended to fix Android file-manager/browser setups that don't allow a local HTML file to load neighboring assets. Open `index.html` in Chrome and tap **Play music** (or the native audio player). Browser autoplay restrictions still apply.
